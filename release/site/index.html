Galion OS

Starting with Open Mind and Hermes.

The full Galion operating system experience: one window, one gradient, ultra-minimal, with Hermes at the centre. Obsidian Open Mind is its heart and its interface, built in Rust so it stays light and lightning fast, and made to run on any processor: Linux, Mac, Windows, Android, iPhone and ARM chips such as Snapdragon. Galion OS is where we are heading, not a finished operating system you can install today. Open source under the MIT License: free for everybody to download and do anything with.

Obsidian Open Mind itself is the stance and the code of the Obsidian stack by Galion Studio: a lightweight, CPU-light Rust foundation where the CPU box owns the loop, the memory and the keys. A GPU is not a special case in this design; it is one more Provider row. License: MIT.

What it is

Obsidian Open Mind is a foundation, not a framework. The processor owns the loop, the skills, the memory and the key box. Video memory is only for a model. A provider is an adapter, not a secret.

The workspace is a plain Cargo workspace under the MIT license. Its contract crate carries the types the rest of the stack agrees on: Machine, Provider, ProviderKind, KeySlot, Surface and Stack, plus Stack::cpu_desk() as the reference shape of a CPU-only box. The schema re-exports the shared time helper, so a consumer of the contract gets it without a second dependency line.

Why a CPU-light Rust foundation

  • The CPU box owns the loop, the memory and the keys. Machine::weights() turns local weights on only when a card has at least 8192 MiB free and the box has at least 8192 MiB of memory. Machine::mouth() needs ordinary memory only, never a card. A CPU-only box is a first-class citizen, not a degraded one.
  • Adding a provider is a new row, not a new program. Provider { id, kind, base_url, key_slot, default_model } covers a laptop Ollama and a remote site with the same shape, and ProviderKind is only Remote or Local. No per-backend code path.
  • Secrets never live in the schema. A KeySlot records only name, present and a hint. The contract types contain no key material, and a test asserts the serialized stack never contains the string sk-.
  • Rust, small, built for footprint. The workspace release profile is tuned for footprint, not throughput: opt-level = "z", lto = true, codegen-units = 1, panic = "abort", strip = true.
  • The Rust parts are already light. A 2026-10-18 snapshot of the pre-workspace binaries put the Rust parts at about 10 MB of RAM and almost no CPU (A-foundation.md); that number is not a measurement of the crates listed below. No accelerator is required to run the foundation, and Open Mind is designed so that accelerators from NVIDIA, AMD or Apple can be added the same way as anything else: as provider rows that expose an OpenAI-compatible HTTP endpoint (A-foundation.md — design, not code; no such row exists yet, TODO(verify)).

Requirements

  • A Rust toolchain with Cargo. The workspace does not pin a toolchain version: rust-version is not set and there is no rust-toolchain.toml.
  • The reference toolchain used to develop this workspace is rustc 1.99.0.
  • The workspace dependencies are Rust crates only: serde, serde_json, chrono and chrono-tz.

License

MIT. The workspace package declares license = "MIT", the stack is released under the MIT license, and a LICENSE file sits at the workspace root.

Status

The foundation is a Rust workspace being ported from programs that still shell out to a Python helper, so read "Rust foundation" as the shape of the foundation, not as a claim about every process on the machine. The known gaps, all measured 2026-10-18:

  • Python helper call sites. The Rust binaries of galion-one and galion-desk still spawn a Python helper at runtime. No crate holds a Python file. Removing the calls is TODO(verify).
  • The Hermes agent and the Node services are not part of this foundation. Hermes is upstream software written in Python, and the Node services run alongside it on the same box. They are named here so that nobody reads "Rust foundation" as the whole machine (A-foundation.md, section 1).
  • No accelerator provider row exists. That path is a design statement, not code.
  • link-watch has no source yet, and openmind-http and openmind-state are planned only.
  • Milestone: 2026-10-31 - published, everything live, fact-checked and timestamped.
  • The repository is not published: there is no remote, no push and no site deployment. Those steps wait for the owner's approval.
  • The list above is what the files say today. Anything not in the files is marked planned and stays out of this page.
