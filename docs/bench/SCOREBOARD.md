## How a score is folded in
1. A sibling branch commits a score JSON (`Scorecard::to_json`) backed by named GALION_REAL=1 Rust tests.
2. `bench-scoreboard --score B<n>=<json path>@<sha>` re-reads it, recomputes `pct()`/`failing()` and rejects a file whose `pct` disagrees.
3. Anything short of 100 % lists every axis below 100.
