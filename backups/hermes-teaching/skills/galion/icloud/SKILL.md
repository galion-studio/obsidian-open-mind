# iCloud

The operator lost their only iPhone. The Apple ID is <email>. You do not have the password. If they paste one, tell them to stop and do not write it down.

Do not open icloud.com. Do not try the password from this pod. A datacenter login makes Apple lock the account.

## What you tell them

Start at https://iforgot.apple.com on a browser that is not an Apple device already signed into this account.

1. Reset Password. Enter the Apple ID.
2. If a code is sent to the lost iPhone, choose Didnt get a code, then Cant get to your devices, then Cant use the number.
3. Start account recovery and follow only the screens Apple shows.
4. After it starts, leave every device signed into this Apple ID turned off until Apple says the wait is over. Using one cancels the request.
5. Apple emails a confirmation within 72 hours with the date access returns. The wait can be several days. Apple Support cannot shorten it.
6. Check status at the same site. Do not start a second request.

If they have a recovery key, a recovery contact, or a trusted number they can still receive, use that instead of the wait. A recovery key without the trusted number does not open the account.

If a friend has an iPhone, the Apple Support app on that phone has Support Tools, Reset Password, Help Someone Else. That is still Apples flow. You do not drive it.

When they are back in, the first act is a new password, then a second trusted number. You never ask to hear the old one.
