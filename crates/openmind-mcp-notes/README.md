# openmind-mcp-notes

Stdio MCP server for a markdown research vault. Read tools do not write. `create_draft_note` and `link_notes` write only under `drafts/`.

The tool list, the audit against `openmind-mcp-stack`, and the vault rules are in [docs/mcp-notes.md](../../docs/mcp-notes.md).

```
openmind-mcp-notes /path/to/vault
```

`OPENMIND_NOTES_VAULT` is used when there is no argument. The process does not bind a port.
